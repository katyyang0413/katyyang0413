# Hi, I'm JingYi (Katy) Yang 

I'm a Computer Engineering student at Trinity College Dublin with an interest in embedded systems, firmware, FPGA design, robotics and software engineering.

I enjoy working on projects that combine software and hardware, and I'm particularly interested in understanding how systems work at a lower level.

- MATLAB

## Projects

### Autonomous Line-Following Buggy
Team project developing an Arduino-based autonomous buggy using IR and ultrasonic sensors, PID speed control, motor control and a PC interface.

### Raspberry Pi Pico Embedded Systems
A collection of individual and team projects using C and ARM assembly on the RP2040, including interrupts, ADC, PIO and hardware control.

### FPGA Digital Systems Design
Verilog projects developed using Vivado and implemented on a Basys-3 FPGA, including a 6-bit Mini-ALU and 21-bit LFSR.

### Networked Turbine Monitoring System
Team project developing a Python-based system connecting wind turbines, a satellite relay and a ground station using TCP/UDP communication and HMAC-SHA256 authentication.

## About This GitHub

Most of the projects here were completed during my Computer Engineering degree before I started actively using GitHub as a portfolio.

At the time, I mainly worked locally using VS Code and kept reports and other project documentation in Google Docs rather than uploading my work to GitHub. I have recently started organising and uploading my previous projects here so that I can keep a record of my work and continue building my engineering portfolio.

For some older projects, not all of the original source files are still available, so the repositories contain the project files and documentation that I was able to recover.
